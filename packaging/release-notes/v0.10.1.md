Public beta release of Nora. The signed and notarized `.dmg` below is
the recommended install path.

## What Nora is

A local privacy layer for statistical analysis on sensitive data. The
data stays on the researcher's machine, and the frontier model
(Anthropic or OpenAI) never sees the raw data. It drives a complete
analysis through sanitized summaries only.

## What you can do with it

- Run statistical analyses in R, Stata, or Python with Claude or GPT
  choosing the model, writing the script, and reading the result.
- Broad coverage across the common analyses: regression, causal
  inference, survival, unsupervised methods, descriptives, and
  marginal effects. Stata, R, and Python emit the same payload
  shape so comparing results across languages reads cleanly.
- Get diagnostic and model-output plots back in chat. They're pure
  functions of the fitted model; raw-data plots stay
  researcher-only.
- Run multiple analyses in parallel sessions. Each session is
  independent, long jobs keep streaming when you switch focus, and
  the sidebar shows a busy dot per active runner.
- Use Anthropic (Claude subscription or API key) or OpenAI (API key).
  Sessions persist across launches: chat history, attached files,
  and result cards reload where you left them. Each provider keeps
  an independent thread within a session, so switching from Claude
  to GPT preserves both conversations.

## What you need

- macOS with Apple Silicon (M1 or later). The `.dmg` is signed with a
  Developer ID Application certificate and notarized through Apple.
- R (`Rscript` on PATH), Stata, or Python 3.10+ with `pandas`. Nora
  calls these as subprocesses; they are not bundled in the `.app`.
- An Anthropic account, an Anthropic API key, or an OpenAI API key.
  The first launch shows the auth screen and stores the credential
  in the macOS Keychain.

## Install

1. Download `Nora.dmg` below.
2. Open the .dmg, drag `Nora.app` to `/Applications`.
3. Launch.

## Verifying the build

```
codesign --verify --deep --strict --verbose=2 /Applications/Nora.app
spctl --assess --type execute --verbose /Applications/Nora.app
```

## What's new in 0.10.1

- Row-count audit extended to the current regression payload name and to `correlation_matrix`, `marginal_effects`, `kaplan_meier`, `factor_decomposition`, `cluster_analysis`. SDC policy lookup honours the basename contract on the source dataset path.
- Kaplan-Meier rare-event counts coarsen via the Cox suppression rule.
- DBSCAN / HDBSCAN cluster results render a sizes-only table.
- Stata and R error excerpts forward the diagnostic body under a denylist posture: length cap, data-shape detect, credential scrub.
- `compose_results` accepts bare `result_id` strings; row labels resolve from the store. Inline markdown budget raised from 30k to 45k.
- Landing oversize-file message themed and auto-dismissed. Tool-output scrollbar matches the dark-panel chrome in light mode.

Full per-feature notes: see `CHANGELOG.md` on this repo.
